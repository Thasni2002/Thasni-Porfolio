- ⚡ **Ultra-Fast & Responsive**: Fully responsive dark luxury aesthetic layout built with Vanilla CSS & HTML5.
- 🎨 **Dynamic Glassmorphism**: Interactive particle background canvas, hover state micro-animations, and vibrant gradients.
- 💼 **Resume-Aligned Showcase**: Showcases full-stack experience, key metrics (30% API performance boost, 75% AI doc processing cut, 99.9% billing accuracy), featured projects, and technical skills.
- 💬 **Interactive Project Modals**: Complete modal popups highlighting tech stack tags and key implementation achievements for each project.

## 💻 Local Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/Thasni2002/Portfolio.git
   cd Portfolio
   ```

2. Open `index.html` in your browser or run with Live Server:
   ```bash
   npx serve .
   ```
